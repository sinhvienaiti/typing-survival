# Last Line

Chạy `pnpm deploy:pack` trong repo game để build production rồi kiểm gói `dist/` bằng bộ kiểm của kit cho `typing-survival`; lệnh trả mã lỗi nếu build hoặc kiểm gói thất bại. Bản demo nhà dùng `pnpm deploy:pack:local`, chỉ cho phép thêm miền `typing-game.local`, vẫn chặn tài nguyên của game khác. Muốn lấy báo cáo JSON sau build, chạy `node src/kit/tools/deploy/check-pack.mjs dist --game typing-survival --json` (thêm `--allow-local-host` cho demo nhà). Hiện cả hai chế độ vẫn bị chặn bởi thư viện model `/assets/space-typing/`; giữ nguyên theo hướng B của chủ dự án, chờ bỏ tàu cũ và thay model riêng. Bản production còn bị chặn bởi nguồn portal `https://typing-game.local` ghi cứng trong cầu nối học. Các lệnh này chỉ build và kiểm `dist/`, chưa tải media hay đưa gói lên máy chủ.
